## Reproduce

Use Python 3.11+ and a fresh virtual environment. The dependency file is a starter specification; record exact versions after verifying the notebooks.

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m jupyter lab
```

Open a notebook, check its working directory and dataset paths, restart the kernel and run all cells. Older paths or additional imports may need adjustment; this documentation change does not claim all notebooks were executed.
