# My optional local inbox

I can keep a new `.ipynb` or `.py` file here while I decide its topic. Inbox files stay local. My main tracker is the GitHub checklist.

The optional local scanner can suggest a topic from the filename. For example, `numpy-arrays.ipynb` maps to `numpy`. If a name is unclear, I choose a key in [my local form](../Track_my_learning.ipynb).

I move reviewed work to its library or ML topic folder before I publish it. I can also save directly in that topic's `notebooks/` folder.
