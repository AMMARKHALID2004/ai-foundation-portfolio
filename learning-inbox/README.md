# My learning inbox

I can save a new `.ipynb` or `.py` file here. The tracker uses its name to select a module when the topic is clear. For example, `numpy-arrays.ipynb` maps to the refresh module. If the name is unclear, I select a module in [my tracking notebook](../Track_my_learning.ipynb) and link the file.

The tracker creates a record in the module. It keeps this original file here. Inbox files stay local until they are reviewed and placed in a module for publication. I can also save my notebook directly in a module's `notebooks/` folder.
