# LLM specialization blueprint

I can start this track after the common foundation and PyTorch. I will confirm the choice with my supervisor. The guide estimates 12–18 weeks.

## Required course sequence

1. [Hugging Face LLM Course](https://huggingface.co/learn/llm-course/chapter1/1): core chapters 1–4 (Transformers, inference, fine-tuning, sharing), 5–6 (datasets/tokenizers), 7 (NLP tasks), 9 (demos). Core: 7–9 weeks.
2. [Full Stack LLM Bootcamp](https://fullstackdeeplearning.com/llm-bootcamp/): selected foundations, augmented models, project walkthrough, UX and LLMOps; 1–2 weeks. Its 2023 framework examples require checking current docs.
3. Advanced coverage: HF chapters 10–12 on data curation, LLM fine-tuning and reasoning, approximately 3 weeks. [CS336](https://cs336.stanford.edu/) is a demanding optional elective (6–12 weeks), not compulsory.

## Repository modules

`01-transformers-inference/`, `02-datasets-tokenizers/`, `03-finetuning-nlp/`, `04-rag-evaluation/`, `05-demos-llmops/`, optional `06-cs336/`. Include tokenization experiments, inference/model comparisons, fine-tuning, RAG/retrieval evaluation and a demo.
