# Machine Learning

**Status: In progress.** This folder contains practical work in data preparation, regression, gradient descent, and scikit-learn workflows. It is an active, incomplete part of the portfolio.

## Topics represented in the notebooks

- Missing values: univariate and multivariate imputation, missing indicators, KNN, and MICE
- Mixed variables and categorical encoding: one-hot, ordinal, and label encoding
- Numerical preprocessing: standardization, normalization, power transforms, and function transforms
- Outlier handling: IQR, Z-score, and winsorization
- Feature preparation: binning and binarization
- Scikit-learn composition: column transformers and pipelines
- Dimensionality reduction: PCA visualization and component selection
- Linear regression: simple and multiple regression, a from-scratch implementation, regression metrics, assumptions, and plane visualization
- Polynomial regression
- Introductory classification: logistic regression with gradient descent and perceptron examples
- Gradient descent: batch, stochastic, and mini-batch methods, step-by-step demonstrations, and a custom gradient descent regressor

## Current scope

The repository now has introductory regression and classification model-building work, with evaluation concepts represented in regression notebooks. Broader model comparison and validation, more advanced classification and regression coverage, and complete end-to-end ML projects remain future work. Deep learning and later AI topics are tracked in the root [progress overview](../README.md#progress-overview).

The accompanying datasets are stored alongside the relevant notebooks. The root [progress tracker](../README.md#machine-learning-progress-tracker) summarizes the current evidence across the portfolio.
