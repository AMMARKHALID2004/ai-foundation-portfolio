# Machine Learning

**Status: In progress.** This folder contains practical work on preparing data and assembling preprocessing workflows. It is an active, incomplete part of the portfolio.

## Topics represented in the notebooks

- Missing values: univariate and multivariate imputation, missing indicators, KNN, and MICE
- Mixed variables and categorical encoding: one-hot, ordinal, and label encoding
- Numerical preprocessing: standardization, normalization, power transforms, and function transforms
- Outlier handling: IQR, Z-score, and winsorization
- Feature preparation: binning and binarization
- Scikit-learn composition: column transformers and pipelines
- Dimensionality reduction: PCA visualization and component selection

The accompanying datasets are stored alongside the relevant notebooks. The root [progress tracker](../README.md#machine-learning-progress-tracker) summarizes the current evidence across the portfolio.
